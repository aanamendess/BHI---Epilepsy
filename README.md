The present study aims to investigate interictal
brain-heart interactions in epileptic subjects com-
pared to healthy controls using the Temple Uni-
versity Hospital’s EEG Epilepsy Corpus (TUEP)
dataset. This approach combines EEG and
ECG data from resting-state recordings to develop a
DL framework for automatic prediction of epilepsy
along with a comparison to traditional brain–heart
interaction (BHI) metrics.
